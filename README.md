# Pharmacy Management System

A Java Swing-based Pharmacy Management System with medicine categories, stock management, cart, checkout, and receipt generation.

## Features

- Medicine categories
- Medicine images
- Strength selection
- Quantity selection
- Stock management
- Add to cart
- Remove from cart
- Automatic total calculation
- Checkout
- Receipt generation

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- IntelliJ IDEA

## How to Run

Download the Windows installer from the Releases section and install the application.

## Project Structure

- `src/` - Java source code
- `installer/` - Windows installer
